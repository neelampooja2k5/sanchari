## 🔗 API ENDPOINTS (Backend)

```
Authentication:
  POST   /api/auth/register        - Register new user
  POST   /api/auth/login           - Login user

Users:
  GET    /api/users/:id            - Get user profile
  PUT    /api/users/:id            - Update profile

Hotels:
  GET    /api/hotels               - List all hotels
  GET    /api/hotels/:id           - Get hotel details
  POST   /api/hotels               - Create hotel (admin)

Attractions:
  GET    /api/attractions          - List all attractions
  GET    /api/attractions/:id      - Get attraction details

Bookings:
  POST   /api/bookings             - Create booking
  GET    /api/bookings/user/:id    - Get user bookings
```

## 🎨 CUSTOMIZATION QUICK GUIDE

### **Change Brand Colors**
Edit: `css/styles.css` (lines 14-23)
```css
:root {
    --primary-color: #667eea;      /* Change main color */
    --secondary-color: #764ba2;    /* Change accent */
    --accent-color: #f5576c;       /* Change highlight */
}
```

### **Add Hotels to Database**
Edit: `backend/server.js` - Search "seedDatabase()"
```javascript
{
    name: 'Your Hotel',
    location: 'Location',
    rating: 4.5,
    price: 150,
    features: ['WiFi', 'Restaurant'],
    reviews: 300
}
```

### **Customize Chatbot Responses**
Edit: `js/chatbot.js` - Add to `sachareResponses` object
```javascript
yourTopic: [
    'Custom response 1',
    'Custom response 2',
    'Custom response 3'
]
```

### **Change App Name**
Replace "Sanchari" with your name in:
- `index.html` (title, logo)
- `login.html` (title, logo)
- `register.html` (title)
- `dashboard.html` (title, sidebar)
- `css/styles.css` (search for branding)

## 📞 SUPPORT & HELP

**Common Issues:**

1. **Map not loading?**
   - Check internet connection
   - Refresh the page
   - Check browser console (F12)

2. **Can't register?**
   - Check all fields are filled
   - Password must be 6+ characters
   - Email validation is required

3. **Backend connection error?**
   - Ensure backend is running (`npm start`)
   - Check MongoDB is running
   - Verify port 3000 is available

4. **Styling looks broken?**
   - Clear browser cache (Ctrl+Shift+Del)
   - Hard refresh (Ctrl+F5)
   - Check CSS file paths

**Troubleshooting Steps:**
1. Check browser console (F12 → Console)
2. Check network tab (F12 → Network)
3. Read error messages carefully
4. Check SETUP_GUIDE.md
5. Review README.md
