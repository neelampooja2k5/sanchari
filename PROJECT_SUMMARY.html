🎨 Customization Guide

1. Change Colors

Edit css/styles.css (lines 14-23):

:root { --primary-color: #667eea; /* Blue */ --secondary-color: #764ba2; /* Purple */ --accent-color: #f5576c; /* Pink */ }

2. Add Hotels

Edit backend/server.js - Add to seedDatabase():

{ name: 'Hotel Name', location: 'Location', rating: 4.5, price: 100, features: ['WiFi', 'Restaurant'], reviews: 250 }

3. Customize Chatbot

Edit js/chatbot.js - Add to sachareResponses:

yourTopic: [ 'Response 1', 'Response 2', 'Response 3' ]

🔗 Backend API Endpoints

Method Endpoint Description
POST /api/auth/register Register new user
POST /api/auth/login Login user
GET /api/hotels Get all hotels
GET /api/attractions Get all attractions
POST /api/bookings Create booking
GET /api/users/:id Get user profile
