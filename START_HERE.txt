## 🚀 RUN IN 3 STEPS

### Step 1: Frontend Only (No Installation)
```
Just open index.html in your browser
```

### Step 2: With Local Server
```
python -m http.server 8000
Open: http://localhost:8000
```

### Step 3: Full Stack (With Backend)
```
Terminal 1: cd backend → npm install → npm start
Terminal 2: python -m http.server 8000
Open: http://localhost:8000
```
